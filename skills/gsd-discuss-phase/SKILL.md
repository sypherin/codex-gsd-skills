# Discuss Phase

## Objective

Execute the `discuss-phase` phase with clear outputs and minimal ceremony.

## Workflow

1. Confirm scope and constraints.
2. Gather only required context.
3. Perform the requested phase action.
4. Add validation checks where applicable.
5. End with next actions.

## Output Contract

Always include:

- Action taken.
- Files or areas touched.
- Validation status.
- Remaining risks or decisions.
